Translator

Browses and edits the real translation files this repo's main app (src/app) reads via @wawjs/ngx-translate: src/i18n/en.json (default language — each string is both the source text shown to translators and the lookup key used in code) and src/i18n/ua.json (a same-length array, positionally aligned to the English one). A row is flagged missing when a language's array doesn't reach that index yet, and untranslated when its value still equals the English source text.
